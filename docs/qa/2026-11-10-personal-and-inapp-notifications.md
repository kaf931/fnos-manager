# 个人推送与应用内消息验收

日期：2026-11-10。运行版本保持 0.4.2，数据库由 schema 32 升级至 33。

## 实现

- 顶部内置渠道增加个人微信（Server酱）、手机推送（Bark）、应用内通知，总计八种，继续从卡片进入配置。
- Server酱支持 SCT 与 sctp SendKey；Bark 默认官方推送地址，支持自建服务，不把 Device Key 当 Bearer Token 发送。
- 应用内通知按现有模板条件处理任务结果、失败扫描和到期提醒，不自动开启或收集全部系统事件。
- 应用内消息复用投递队列及成功记录，新增 read_at 字段保存已读状态，不引入并存的消息日志表。正文保存发送时内容，读取不依赖后续模板配置。
- 消息入口显示未读数，支持全部／未读筛选、详情自动已读、所选已读、全部已读与批量删除。桌面公共分页，小屏幕公共紧凑列表和按钮组。详情按纯文本展示，不执行 HTML。
- 保留数量和清理复用投递记录设置，默认每账号 200 条（与其他投递合计），上限在应用清理中设置。
- 共用公共大弹窗、记录选择、列表、分页、徽章；增加通用紧凑记录表格尺寸变体以适配四列。弹窗内更多菜单挂载到当前 dialog，操作后收起。
