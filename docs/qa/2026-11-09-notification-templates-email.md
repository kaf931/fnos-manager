# 2026-11-09 通知模板与 SMTP 邮箱

本轮替换单一通知整页表单，运行版本保持 0.4.2。

## 实现

- 每个账号最多 50 个命名通知模板，各自配置渠道、消息内容、通知条件和扫描通知，可独立启用。符合条件的已启用模板同时入队。
- 新增 SMTP 邮箱，合计 14 种渠道。支持主机、端口、TLS／STARTTLS／不加密、账号授权码、发件邮箱、最多 20 个收件邮箱、邮件标题和正文变量。
- SMTP 默认验证证书，STARTTLS 必须成功升级；仅发送纯文本摘要，不读取附件、文件或 URL。认证、地址、证书及永久拒绝不自动重试；临时错误沿用队列重试。全部收件人接收才确认成功，部分接收失败不自动重发。
- schema31 将旧通知配置迁移为默认模板，保留旧修订号和投递记录，移除旧 notification_settings／notification_options 表。队列按账号、模板、事件去重；模板修改、停用、删除只取消自身待处理记录，历史记录保留模板名称。
- 原单配置 API 通过同一模板仓储访问默认模板，不保留第二套存储或队列。
- 首页参照网络唤醒，复用 task-toolbar、搜索框、桌面选择器／手机横向筛选、ConnectionCards、EmptyState、PullRefresh；开关使用 SwitchControl。新增／编辑复用 ReactDialog、task-form-body、form-grid、NativeSelect、PasswordField，无新增专用 CSS。
- 配置弹窗移除列表 ID 和创建／修改时间再提交，符合 Nest DTO 白名单。凭据使用 new-password 语义与独立字段名，地址字段不使用登录账号标识。
