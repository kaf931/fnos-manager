# 通知编辑请求与消息详情适配

## 修复

- 慢速编辑请求返回时，可能替换后来打开的内置渠道表单；测试通知返回时，也可能关闭正在填写的新表单并跳转记录。为所有模板打开入口统一更新请求序号，旧响应不再抢占当前界面，测试通知仍正常提交。
- 提醒编辑器的“配置通知模板”和主工具栏的“全部模板”共用相同入口，均使先前编辑或测试的跳转失效。
- 消息详情不再复用终端日志框。新增公共 RecordDetail 阅读区域，沿用公共弹窗、工具栏和配色，正文使用正常文本字体、保留换行、连续长字符串可换行；标题、时间和正文使用同一个可滚动阅读区域，取消日志框的 24dvh 限高和嵌套滚动。

## 验证

新增三项异步回归测试，覆盖慢编辑、慢测试响应与提醒编辑器配置入口；前两项已先复现失败。消息已读队列、列表返回与纯文本安全渲染等原测试继续通过。全项目 1090 项测试、类型检查、生产构建、ESLint、格式及 diff 检查通过。独立审查提出的遗漏入口已统一，复审未发现明确问题。

浏览器使用真实 React/Semi 组件、生产 CSS 与模拟数据：

- 旧编辑请求延迟 6 秒，切换邮箱模板并填写名称后，旧响应返回未替换邮箱表单或名称。
- 390×844 小屏幕验证长标题、多段正文和连续长链接。阅读区宽度与滚动宽度均为 352px，无横向溢出；内容高 1257px，可见高 603px，父内容区没有额外溢出，正文不再单独限高。
- 滚动到底后返回按钮仍可见，点击能正常返回消息列表。
