# 2026-11-09 通知渠道扩展

运行版本保持 0.4.2。复用原任务通知弹窗、公共表单、密码输入、选择器、折叠说明与投递记录，无新增专用 CSS。

## 能力

- 通用 Webhook、企业微信、钉钉、飞书、Telegram，每账号选择一个渠道。
- 平台原生文本封装；Telegram Bot Token／Chat ID；钉钉、飞书原生签名；通用 Webhook HMAC-SHA256 时间戳和最终正文签名。
- 支持 JSON 自定义请求头、已列明变量的消息模板。通用 Webhook 使用 JSON 对象模板，递归替换字符串值后重新序列化；不执行代码或表达式。
- 校验请求头、变量、模板结构和长度；拒绝传输控制头、重复头、换行注入和冲突鉴权配置。消息超限在投递记录明确失败，不无意义重试。
- 平台 HTTP 200 仍检查业务确认，错误仅记录固定原因与业务码，不保存平台原始响应；读取响应限制 64 KiB。网络重试、账号隔离、事件摘要与清理逻辑沿用。
- schema 30 新增 notification_options 表；原通知设置与队列原文保留，无配置时仍采用通用 Webhook 默认协议。
