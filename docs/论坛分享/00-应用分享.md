## 逛了一圈论坛，我决定当一回“秦始皇”

飞牛论坛里有不少实用的应用，也确实帮我解决了很多问题。但用着用着，我始终有两个不太舒服的地方。

**一个是界面。** 有些工具的功能很扎实，设计却像是停在了“能用就行”：按钮、表格、弹窗各有各的风格，放在飞牛桌面里，总感觉不够协调。

**另一个是分散。** 加个桌面图标要打开一个应用，设置计划任务再打开一个，连接 SSH 又是另一个。功能越来越多，窗口也越来越多，明明只是管理同一台 NAS，却要不停切换界面。

于是，我决定自己动手——**当一回 NAS 工具界的“秦始皇”，把这些常用功能统一起来。**

不是为了给首页多堆几个按钮，而是让入口、布局、交互和视觉风格都尽量统一。由此就有了现在的 **NAS 管家**。

## 五个菜单，安排日常管理

| 菜单            | 它能帮你做什么                                   | 一个常见场景                         |
| :-------------- | :----------------------------------------------- | :----------------------------------- |
| 🧩 **桌面图标** | 给 Docker 应用、自定义链接及管家菜单创建桌面入口 | 把常用服务放到桌面，少记几个端口     |
| ⏱️ **计划任务** | 定时启停程序、控制容器、运行脚本，联动网络设备   | 工作日前唤醒电脑，夜间执行维护脚本   |
| 💻 **SSH 终端** | 多标签连接、文件管理、快捷指令、监控与 AI 助手   | 一边查看资源，一边通过终端处理问题   |
| 🗂️ **存储管理** | 分析空间、检查重复文件、批量改名、查看处理记录   | 找出大文件，整理重复照片和杂乱文件名 |
| ⚡ **网络唤醒** | 扫描局域网、批量添加设备、唤醒与 SSH 电源控制    | 用一直在线的 NAS 唤醒局域网电脑      |

## 常用菜单，也能成为独立桌面图标

现在 **桌面图标支持 NAS 管家类型**。除了给 Docker 服务和网址创建入口，还能把 **SSH 终端、计划任务、存储管理、网络唤醒、系统设置、桌面图标** 分别放到飞牛桌面。

例如，创建一个 SSH 终端图标：打开 **桌面图标 → 添加图标 → 管家功能**，选择 SSH 终端并保存，再点击 **添加到桌面**。以后直接点击这个图标，就只显示 SSH 终端内容，不显示主应用的侧边导航或手机底部导航；连接仍由你手动发起。

**统一管理，也允许按需直达。** 独立入口共用主应用的数据和配置，不必重复设置，也不依赖固定内网 IP。入口需要同一台 NAS 上的 NAS 管家已安装并运行，不能作为脱离主应用的独立软件使用。

## 功能统一，界面也要统一

我比较在意的一点是：**打开不同菜单，不应该像进入了五个不同的软件。**

所以，搜索、筛选、按钮、下拉框、表格、分页、弹窗和滚动条，都尽量复用同一套组件与公共样式；视觉上参考飞牛官方应用的简洁布局，让第三方工具也能自然地待在飞牛桌面里。

### 🖥️ PC：把空间留给内容

桌面端使用清楚的表格、卡片和侧边导航。SSH 连接后进入完整工作区，支持多标签，左右面板可以调整宽度；存储管理也有独立工作区，处理文件时不用在一堆按钮之间来回找入口。

### 📱 手机：认真适配，不是简单缩小

移动端对列表、筛选和操作入口做了单独调整：卡片展示、底部导航、底部弹出面板、下拉刷新，以及更适合触摸的操作方式。

**目标很简单：在电脑上用得顺手，在手机上也能优雅地完成事情。**

## SSH 里，还放了一个 AI 助手

支持配置多个供应商，协议包括 **OpenAI、Claude、Ollama、Gemini、GLM、MiniMax、DeepSeek、MiMo**。

填写接口信息后，可以测试连接、读取模型列表，再通过对话让 AI 协助检查当前 SSH 主机。回答支持 Markdown；命令既可以逐条审核，也可以在主动选择静默模式后自动执行。

它依然围绕当前连接工作：**先明确目标主机，再描述要处理的任务。**

## 从哪里开始？

1. 在飞牛应用中心通过 **手动安装** 选择本文附件中的 `.fpk` 安装包。
2. 安装并启动后，使用具有管理权限的飞牛账号，从桌面打开 **NAS 管家**。
3. 先从自己最常用的菜单开始；需要系统能力时，再完成相应授权或连接配置。

当前项目构建包为 **v0.2.52 / x86_64**，要求飞牛 **1.2.0800 或更新版本**，依赖 **Node.js v22**。安装前请确认设备架构与包一致；实际分享时以附件包的版本为准。已有 NAS 通过 SSH 替换运行文件后，应用中心登记版本可能仍是旧版，不能据此判断实际运行版本。

部分计划任务需要独立的飞牛官方授权。备份任务触发、创建快照及通用系统缓存清理，目前没有作为可执行功能开放；不会把“菜单里有一个名字”当作“已经实现”。
