# NAS 管家——Android 设备接入教程

> 📱 **让 NAS 成为 Android 设备的远程操作入口。**  
> 现在你可以在远程连接中接入支持 ADB 通信的手机、平板、电视盒子等设备，以极其优雅的方式远程控制 Android 设备。

本篇适用于 **NAS 管家 0.4.2 及以上版本**，从第一次连接开始，介绍无线配对、NAS USB 接入、投屏和常用操作。

---

## 先选择一种连接方式

| 连接方式 | 适用情况 | 需要准备 |
| :------- | :------- | :------- |
| **网络调试** | 不接数据线，通过网络访问 Android 设备 | 设备开启网络／无线调试，NAS 能访问设备的 IP 和端口 |
| **NAS USB 设备** | 设备可以通过数据线连接 NAS | 支持数据传输的线缆、USB 调试及设备授权 |

**真正连接设备的是 NAS。** 浏览器所在的电脑或手机能访问设备，不代表 NAS 一定能访问；插在电脑上的 USB 设备，也不会出现在 NAS 的设备列表中。

应用已内置 ADB 与投屏所需组件，不需要额外安装 Docker。设备仍需支持并允许 ADB 调试，并非所有 Android 产品开放的能力都一样。

## ① 在 Android 设备上开启调试

手机／平板一般可以在 **设置 → 关于手机／关于设备** 中连续点击版本号，按系统提示开启开发者选项，再进入开发者选项开启所需的调试功能。不同品牌的菜单名称和位置可能不同。

- 无线连接：开启 **无线调试**，并允许当前网络使用调试。
- USB 连接：开启 **USB 调试**，用数据线连接 NAS 后，在设备上允许调试授权。

Android 官方的配对码无线调试方式面向 Android 11 及以上设备；电视盒子等产品是否提供该入口，要看厂商系统。详见 [Android 官方 ADB 文档](https://developer.android.com/tools/adb#wireless)。

## ② 无线配对并添加连接

### 先分清两个端口

无线调试里通常会出现两组地址，**它们用途不同，不能直接混用**。

| 信息 | 从哪里查看 | 填到哪里 |
| :--- | :--------- | :------- |
| **设备 IP 与连接端口** | 无线调试首页的“IP 地址和端口” | 主机地址、连接端口 |
| **配对端口与六位配对码** | 点击“使用配对码配对设备”后的弹窗 | 配对端口、配对码 |

例如，无线调试首页显示 `192.168.10.50:37123`，配对弹窗显示 `192.168.10.50:40215`，则主机地址填 `192.168.10.50`、连接端口填 `37123`、配对端口填 `40215`。六位码按手机当前显示的填写，不使用教程里的示例端口。

### 在 NAS 管家里填写

1. 先记录无线调试首页的 **IP 地址和连接端口**。
2. 打开 **使用配对码配对设备**，保持配对弹窗打开。
3. 打开 **NAS 管家 → 远程连接 → 新增连接**；小屏幕点击列表顶部的 **＋**。
4. 连接协议选择 **ADB**，连接方式选择 **网络调试**。
5. 填写连接名称、主机地址和连接端口。
6. 首次接入时，填写当前弹窗中的 **配对端口** 和 **配对码**。
7. 点击 **保存连接**，等待配对和保存完成。
8. 回到连接列表，点击设备卡片上的 **连接**。

> 💡 配对码和配对端口来自临时弹窗。若弹窗已关闭或信息已变化，请重新打开并填写当前值。

已在同一 NAS、同一应用用户下完成授权的设备，后续可以留空配对信息。需要重新配对时，编辑原连接即可，不需要寻找单独的“无线配对”菜单。

如果设备重启或重新开启无线调试后无法连接，先检查首页的 IP 和连接端口是否变化，再编辑连接信息。

### 设备已经开放 ADB 网络端口怎么办？

部分电视盒子或其他 Android 设备提供固定的网络调试端口。按照设备实际信息填写主机地址与连接端口，已授权且不使用配对码机制时，配对字段留空。

不要直接把所有设备的端口都填写为 `5555`，以设备提供的地址和端口为准。

## ③ 通过 NAS USB 接入

1. 用支持数据传输的 USB 线，将 Android 设备连接到 **NAS 的 USB 接口**。
2. 在设备上开启 **USB 调试**，查看并允许调试授权提示。
3. 打开 **远程连接 → 新增连接**，连接协议选择 **ADB**。
4. 连接方式选择 **NAS USB 设备**，点击 **发现设备**。
5. 选择状态为 **可连接** 的设备；也可手动填写已确认的设备序列号。
6. 填写名称并保存，回到列表点击 **连接**。

| 显示状态 | 处理方法 |
| :------- | :------- |
| 待授权 | 查看 Android 屏幕上的 USB 调试提示，允许后再次发现设备 |
| 离线 | 检查设备状态和数据线，重新连接后再发现 |
| 未发现设备 | 确认数据线插在 NAS 上、线缆支持数据传输，并已开启 USB 调试 |

本模式不需要填写 IP、连接端口或无线配对码。

## ④ 投屏和设备操作

连接后进入 Android 工作区。**投屏**显示设备画面，可以点击、触控和使用键盘输入。终端、文件和设备信息通过侧边面板打开，小屏幕使用底部面板；再次点击对应按钮可以收起。

### 投屏清晰度

打开 **设备操作 → 投屏清晰度**：

| 档位 | 视频最长边上限 | 适用情况 |
| :--- | :------------- | :------- |
| 流畅 | 720px | 优先减少传输量和解码负担 |
| 均衡 | 1280px，默认 | 日常操作 |
| 高清 | 1920px | 更重视文字和画面细节 |
| 原始分辨率 | 不限制投屏尺寸 | 希望保留设备原始画面尺寸 |

画面保持设备比例，低分辨率设备不会强行放大。切换会重新建立投屏，**不会修改手机自身的屏幕分辨率**。当前选择在本次投屏组件存续期间保留，下次重新打开使用默认档位。

### 屏幕、按键和音量

**设备操作**中提供返回、主页、最近任务、唤醒屏幕、熄灭屏幕、旋转设备屏幕、实体屏幕开关和音量调整。

- **唤醒屏幕**：发送唤醒按键，不会跳过 Android 锁屏。
- **熄灭屏幕**：让设备进入休眠。
- **关闭实体屏幕**：尝试关闭设备自身屏幕，同时保留投屏；恢复时选择 **打开实体屏幕**。实际效果取决于设备支持。

### 解码与全屏

支持 WebCodecs 时默认使用浏览器选择的解码实现，不强制硬件解码；不支持时使用软件解码。遇到解码失败或画面不显示，可以在 **设备操作**中选择 **开启软件解码**，也可以降低清晰度重试。

进入全屏后会显示可展开／收起的工具栏。轻点顶部按钮切换展开状态，拖动该按钮可以调整位置；VNC、RDP、Android 共用这套交互。按 **Esc** 或点击 **退出全屏**可以返回。

飞牛宿主或浏览器可能限制全屏请求；若提示未获允许，可继续在普通窗口操作。

## ⑤ 文件、终端和应用安装

| 功能 | 使用方法 |
| :--- | :------- |
| **终端** | 打开侧边终端，执行设备允许的 Android Shell 命令 |
| **文件** | 浏览目录，使用路径栏与前进／后退；右键或长按文件打开操作菜单 |
| **上传／下载** | 在文件面板发起传输，通过“传输”查看状态；下载完成后点击“保存文件”交给浏览器保存 |
| **重命名／删除** | 在文件菜单中操作，按弹窗提示确认 |
| **应用安装** | 在文件面板顶部、刷新按钮左侧点击“应用安装”，选择本地 APK 并安装 |
| **设备信息** | 按分组查看设备、系统和硬件信息，支持搜索 |

单个文件上传、下载及 APK 安装上限为 **256 MiB**，同一前端会话依次传输。APK 从访问网页的电脑或手机中选择，目前不支持直接选择 NAS 上的 APK 安装。

文件访问使用 Android 调试用户权限，不会自动获取 root。遇到无权限访问的目录或设备限制安装时，查看错误原因；拥有 NAS 管理权限并不等于拥有 Android 系统权限。

## ⑥ 连不上或黑屏时怎么排查？

打开侧栏的 **连接日志**，先看失败发生在哪个阶段，再检查对应配置。

| 现象 | 优先检查 |
| :--- | :------- |
| 配对失败 | 配对弹窗是否仍打开，配对端口和六位码是否已变化 |
| 已配对但连接失败 | 连接端口是否误填成配对端口，NAS 到设备是否互通 |
| USB 待授权／未发现 | 调试授权、数据线、USB 接口及设备是否确实插在 NAS 上 |
| 设备已连接但投屏失败 | 设备上的授权提示、编码器状态；尝试降低清晰度或开启软件解码 |
| 能显示画面但无法操作 | 设备是否允许调试控制，是否有厂商额外权限或系统限制 |
| 某些应用画面是黑的 | 受保护的画面可能禁止截屏或投屏，并非整个连接失败 |

向他人反馈时，可以使用连接日志里的复制按钮提供日志，并说明接入方式、设备型号、Android 版本以及使用飞牛 App 还是浏览器打开。

连接日志和传输记录只保留当前会话，**关闭连接前先复制需要的排查信息**。

## 最后说明

设备配置会随 NAS 管家的配置备份导出，但 ADB 私钥与配对码不会放进配置包。将配置恢复到另一台 NAS 后，需要重新授权或配对。

无线调试应在可信网络中使用，不要把设备的 ADB 端口或应用内部 ADB 服务直接映射到公网。远程访问 NAS 管家与直接对公网开放 ADB，是两种不同的方式。
