# Docker 排查

1. 先明确用户要检查的容器；不明确时使用 `docker ps -a` 获取名称和状态。
2. 针对目标容器检查状态及退出原因，避免输出完整环境变量和认证配置。
3. 必要时使用 `docker logs --tail 100 <容器名>` 查看近期日志，说明与故障相关的内容。
4. 先给出诊断和建议；重启、删除或修改配置必须属于用户请求范围，并遵循应用当前的审核／静默权限。
5. 操作后验证结果。不假设某个容器名称、目录或端口一定存在，不自动安装依赖。
