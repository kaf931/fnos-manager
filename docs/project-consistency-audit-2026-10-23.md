# 项目一致性检查与修复

本轮按公共样式、代码实现、功能逻辑、文件职责依次检查。只修改有源码或回归证据的问题，保留业务专属布局；没有将所有独立样式都视为错误。

## 修复内容

- SSH 压缩格式使用公共 NativeSelect；选择框基础外观从移动布局文件抽到 shared-select.css，工具栏保留自身宽度规则。
- 公共选择框默认将选项挂载到所属原生 dialog 内，修复批量管理中下拉已展开但选项被弹窗遮挡的问题；显式挂载配置仍优先。
- 空间分析和系统监控共用 SortableHeader；排序状态放在表头上，移除重复排序图标实现。
- 删除无引用的 brand、brand-icon、count、status-dot、task-connection 旧样式，保留仍被使用的移动状态样式。
- 文件传输切换/关闭会话后，旧请求不能覆盖新界面或阻塞当前会话加载。
- 应用附件移动刷新回到第一页，关闭附件管理后不再发起刷新请求。
- 飞牛 SDK 初始化失败时也能回退应用目录选择器，并允许重试。
- 局域网发现依然限制探测范围，但广播地址按真实网络掩码生成，修复非 /24 网络的广播地址错误。
- 删除常用命令右键菜单未使用的重复绑定路径，测试使用实际渲染路径。
- 安装包生成脚本直接输出版本号.fpk；版本测试改为验证包与 manifest 一致，不再写死旧版本号。
- 测试构建适配公共 Semi 选择组件的浏览器依赖；真实组件仍参与 UI 测试。
