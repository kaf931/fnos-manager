# ADB 远程连接

远程连接支持 ADB 网络调试和连接到 NAS 的 USB Android 设备。设备必须开启开发者选项及调试，并确认设备上的授权提示；本功能不会获取 root 权限。

## 连接

新增连接选择 ADB。网络模式填写 Android 无线调试首页的 IP 和连接端口。首次无线调试，在新增或编辑连接时填写配对端口和当前六位码；保存时先配对、成功后再保存连接。配对端口来自手机“使用配对码配对设备”弹窗，通常与连接端口不同；保持手机配对弹窗打开直到完成。已授权的设备可留空。需要重新配对时编辑原连接即可；配对码不写入连接配置。

USB 模式要求设备通过数据线插在 NAS 上。序列号／设备选择与发现按钮使用公共输入操作行；没有发现设备时不显示空下拉框。发现设备后可选择已授权设备，或选择“手动输入序列号”。待授权和离线设备显示中文状态，不能直接选为可连接设备。插在访问网页的电脑上的设备不会自动出现在 NAS USB 列表。

## 侧栏

资产列表沿用远程连接工作区；ADB 详情提供投屏、终端、文件、设备信息、传输和连接日志。应用安装位于文件路径栏刷新按钮左侧，沿用公共安装弹窗及 APK 传输通道。投屏控制包括返回、主页、最近任务及全屏，移动端使用已有底部面板。终端使用与资产列表一致的侧边面板，移动端显示公共底部面板；打开终端时保留投屏。“设备操作”使用公共下拉菜单，按导航、屏幕、音量、解码分组。提供返回、主页、最近任务、唤醒屏幕、熄灭屏幕、旋转设备屏幕、关闭实体屏幕（保持投屏）、打开实体屏幕、音量增加／降低及软件解码切换。长菜单与 VNC／RDP 共用公共滚动高度限制。唤醒与熄灭使用 Android 独立按键（224／223），重复点击不会反向切换；操作需要已建立的投屏控制通道，不依赖已显示首帧。唤醒不会跳过系统锁屏。“熄灭屏幕”发送休眠按键；“关闭实体屏幕（保持投屏）”使用 scrcpy 显示电源控制，不发送休眠按键，恢复时选择“打开实体屏幕”。实体屏幕开关及旋转受设备系统支持和调试授权约束。再次点击已打开的面板按钮可收起。

设备信息复用 SSH 系统监控的分组卡片与键值行，将已知设备、系统、硬件、安全启动、区域、连接、运行环境、分区构建及系统服务属性转换为可读字段。支持统一搜索，搜索时展开匹配分组；没有数据的分组不显示。已移除原始属性入口，不猜测厂商私有调试字段含义。服务列表使用真实服务名与中文运行状态。设备代号、产品名称、板型和 SKU 的值相同时仅保留首项，不同变体仍显示；不会按值跨类别删除有独立含义的安全状态。供应商补丁兼容两种属性名，支持供应商 API 与元数据加密状态。常见启动原因、语言区域、构建类型和签名标签转换为可读文字，构建时间优先使用 UTC 时间戳。`ro.secure` 仅显示为“ADB 默认降权策略”，不表示 Android 安全模式，也不据此断言当前进程或设备是否有 root 权限。

侧栏固定顺序为全屏、投屏、终端、文件、设备操作、设备信息、传输、连接日志、断开；仅失败／断开后的重连入口位于末尾，避免其他按钮移位。投屏使用公共手机轮廓图标，设备信息和传输复用 SSH 监控与双向传输图标。

投屏使用 scrcpy 3.1。支持 WebCodecs 的环境默认使用浏览器自动选择的解码实现，并不强制硬件加速；不支持时使用 TinyH264，也可手动强制软件解码；软件解码性能取决于客户端，受保护内容可能无法显示。解码或启动失败会显示具体阶段提示。

终端使用 Shell v2，窗口尺寸通过独立协议通道传递。文件面板与 SSH 共用路径栏、四列列表和右键／长按菜单外壳，支持排序、后退／前进；仅展示 ADB 已实现的操作。文件访问受 Android 调试用户权限约束。单次上传、下载和 APK 安装限制 256 MiB，同一前端会话依次传输，可取消；下载完成后在传输面板点击保存文件。APK 安装仍受设备安装策略限制。

日志和传输界面仅保留当前会话。关闭会话释放终端、投屏及未完成传输。设备配置参与配置备份；ADB 私钥和配对码不放进配置导出包。恢复配置后需要在目标 NAS 重新配对。

## 运行依赖

应用自带 x86_64 或 ARM64 ADB、依赖库和 scrcpy server，无需安装 Docker。每个应用用户使用独立回环 ADB server、受限目录和授权密钥，不使用全局 ADB 服务。浏览器通过既有登录、CSRF 和一次性 WebSocket 票据访问 NAS。不能直接向外网暴露 ADB server。

`third-party/adb` 提供构建说明，`third-party/scrcpy` 记录固定版本、校验值及许可证。打包时校验原生库完整性及 ELF 架构。后台服务和前端会话分别对进程、连接、输入、视频积压和文件大小限额。

应用安装使用公共小尺寸弹窗，当前 APK 来源是手机／电脑本地文件，经浏览器选择后上传。官方 `pickUserFile` 支持选择并授权 NAS 文件（含宿主支持的外接存储和远程挂载分组），但本应用尚未接入 NAS 授权路径读取并安装的通道。SDK 的 `external` 分组表示 NAS 外接存储，不表示客户端本地文件。
