# SSH AI Skills

2026-10-23，运行版本 0.2.52，数据库 schema12。

## 使用

在系统设置或当前 SSH 的 AI 面板打开技能管理。新增可编辑独立 SKILL.md；导入可选择 SKILL.md 或 ZIP。“下载技能包”在当前技能管理中展开 ZIP、官方快捷下载和 HTTPS 地址输入，不叠加导入弹窗。预览名称、文件数、大小、摘要后确认导入，默认禁用。启用后模型按需读取正文和资源。

完整包保存在应用数据目录 `ai-skill-packages/<包ID>`，SQLite 仅保存定义、索引、修订和授权元数据。应用升级保留这些文件。支持 references、scripts、assets；资源面板分页显示文本并允许下载二进制文件。替换生成新修订，旧的未执行提案会失效。

## 边界

ZIP 最大10MiB、512项、展开32MiB、单文件4MiB；拒绝越界路径、符号链接、重复或冲突路径、CRC异常和歧义入口。单一外层目录会规范化。远程下载仅接受无凭据 HTTPS，逐跳验证公网 DNS 并固定解析地址，最多3次跳转、20秒超时。不发送应用凭据。

模型通过 read_skill、list_skill_resources、read_skill_resource 渐进读取，每次文本64KiB、每轮256KiB。prepare_skill_runtime 是独立的执行提案，遵循当前审核或用户主动开启的静默模式；不会在导入时执行代码。同步到当前 SSH 用户 HOME 下 `.local/share/nas-manager/skills/<账号摘要>/<技能ID>/<包摘要>`，保留原始脚本并校验文件，通用包不自动安装依赖。

飞牛官方包固定 0.5.1，SHA256 为 `318038b6e50599297dc83dc23550cc405a31dd3c062c7037c90b98383170cb2a`。本地上传相同原包也可识别。仅官方包提供授权流程，浏览器登录和权限确认由用户完成；一次性代码通过专用接口送给原 CLI，不进入聊天。CLI 登录态保存在当前 SSH 用户独立目录，数据库和模型均不接收 token。兑换成功但探测失败可重试验证，退出本地授权不等于撤销 NAS 端授权。
