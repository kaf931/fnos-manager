# 统一操作记录

入口为「系统设置 → 操作记录 → 查看」。可按操作类型、结果筛选和分页，显示操作者账号 ID、目标摘要、开始/结束时间及结果。每个账号仅能读取自己的记录。

覆盖范围：

- SSH 文件管理删除、改名。
- 存储管理批量改名、撤销改名、重复副本删除或移动。
- 配置合并恢复；同一恢复请求重试不重复登记。
- 网络设备重启、关机，包括计划任务调用的设备电源控制。
- AI 审核或静默执行的命令、技能操作。

任务本身仍使用计划任务的执行历史，读取文件、下载文件和普通 AI 对话不写入操作记录。

## 结果含义

| 结果 | 含义 |
| --- | --- |
| 进行中 | 已登记，实际操作尚未确认完成 |
| 成功 | 执行入口已确认完成；电源命令成功不等同设备已完成启动或关机 |
| 部分完成 | 批量操作中部分项目已完成 |
| 失败 | 执行结果明确为失败 |
| 已中断 | 服务中断或外部请求异常，实际结果可能未知；先核实目标再决定是否重试 |

外部文件和电源操作无法与本地 SQLite 组成同一事务，因此先登记、后执行，再更新状态。更新最终记录失败会保留实际操作返回结果，防止误导用户重复操作；未结束记录在服务重启后转为已中断。配置恢复在数据库事务内原子登记，不因网络重试重复生成记录。

## 数据范围

默认每账号保留最近 1000 条已结束记录，可选择 100、500、1000、5000。保存较小上限后会清理超出的已结束记录，进行中记录保留。记录显示时间使用中国标准时间，数据库保存 UTC 毫秒。

记录仅包含受控摘要：文件名或文件数量、设备配置名称、AI 动作类型与会话标识、配置恢复数量。不会复制命令正文、技能参数、输出、对话内容、完整目录路径、密码、API Key 或原始异常。文件名或设备名称由用户定义，请勿将秘密写入名称。

记录保存在本机 SQLite，不发送到 Webhook，不包含在配置备份中。这是应用内的操作追踪，不能替代主机级不可篡改审计；拥有 NAS/root 或数据库访问权的人仍可修改数据库。
