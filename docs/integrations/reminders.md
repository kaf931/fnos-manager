# 通知中心：记事与提醒

主菜单“通知中心”首页以公共入口卡片展示“提醒事项”和“通知模板”，手机从“更多”进入。点击卡片进入列表，使用“返回通知中心”回到首页；往返保留列表搜索状态。

## 创建事项

在提醒事项中点击“新增事项”，填写名称和记事内容。时间、渠道和启用状态按需要选择：

- 不启用提醒：作为记事或待办保存，可以不填时间。
- 启用提醒：选择时间及至少一个已启用的通知模板。符合选择条件的可用模板分别发送通知。
- 时间统一为北京时间，与计划任务一致。支持单次、每天、每周和每月；每周沿用首次日期的星期，每月沿用首次日期，目标月没有该日时取月末，下一月仍按原始日期计算。

“标记完成”会停止提醒并取消尚未发送的通知。“重新打开”恢复为待办，不自动启用旧提醒；可编辑时间后重新启用。“延后15分钟”仅调整下一次时间，重复提醒的原始日期保持不变。修改延期事项的文字不会丢失已设置的延期时间。

## 通知与记录

提醒复用现有通知模板和发送队列。模板的任务结果条件用于任务通知，不会过滤手动选择模板的到期提醒。正在使用的模板需先从启用的提醒中移除或暂停提醒，才能停用或删除。

模板消息可使用 `{{name}}`、`{{content}}`、`{{dueAt}}` 等变量。留空使用默认提醒内容；提醒时间变量按北京时间显示，Webhook 原始 JSON 保留带时区的 ISO 时间。记事正文不写运行日志。

投递记录仍在“存储管理 → 应用清理 → 投递记录”，沿用已有保留上限。一个提醒使用多个模板时分别记录结果；“已接收”表示渠道接收，不等同于设备已读。提醒本身为用户数据，不随历史记录清理；每账号最多保存500个事项，可自行删除。

NAS 重启后，错过的到期提醒补发一次；重复提醒直接计算未来的下一次，不逐条重放停机期间的所有周期。入队和推进时间位于同一数据库事务，防止重启或重复调度造成同一事件重复入队。提醒编辑、暂停、完成或删除会取消该事项尚未发送的通知；已经被渠道接收的消息无法撤回。
