# 通知中心：记事与提醒

通知中心顶部展示内置通知模板，下方展示提醒事项。手机从“更多 → 通知中心”进入，通过“全部模板”管理渠道；“更多 → 应用消息”查看应用内通知。

## 创建与编辑

点击“新增事项”，填写名称、内容和提醒时间，选择至少一个已启用且配置完整的通知模板。保存后直接启用，暂停使用事项卡片上的开关。时间统一为北京时间。

重复支持以下规则：

| 选项 | 行为 |
| --- | --- |
| 单次提醒 | 在指定时间提醒一次 |
| 每天 | 每天在指定时间提醒 |
| 每周 | 沿用首次日期的星期 |
| 每月 | 沿用首次日期；目标月无该日时取月末，下一月仍按原日期计算 |
| 法定工作日（中国大陆） | 排除公告放假日期，包含调休补班日；其余日期按周一至周五判断 |
| 法定节假日（中国大陆） | 按国务院公告的放假日期提醒，包含公告中的连休/调休；不包含普通周末 |
| 自定义 | 多选周一至周日，至少选一天；在所选日期的指定时间提醒 |

“标记完成”停止提醒并取消未发送通知；编辑已完成事项不会重新启用。重新打开后，可编辑保存或通过卡片开关启用。更换重复规则或自定义周几会重新计算下次时间。

## 中国大陆日历

内置 2026、2027 年日历，来源为 [holiday-cn](https://github.com/NateScarlet/holiday-cn)，每年数据附国务院公告链接。存在启用的法定日期提醒时，后台每 6 小时尝试更新当年及下一年；验证成功后保存到应用数据目录的 `reminder-calendars`，网络故障不覆盖已有日历。

缺失年份不按普通周末猜测。新建或编辑时会先尝试获取缺失年份，仍不可用时明确提示；已运行提醒跨入未知年份时保持启用并显示“等待日历”，获取数据后恢复排程。到期消息沿用已有通知队列和去重机制，不会因等待日历反复发送同一条消息。

## 模板与记录

到期提醒向所选的可用模板分别发送，不受模板“任务通知条件”过滤。正在使用的模板需先从启用提醒中移除或暂停提醒，才能停用或删除。

暂停后删除部分关联模板，重新启用时会移除已删除引用；所有关联模板都已删除时需重新配置。投递记录可从事项菜单或存储管理的应用清理进入，支持查看状态、批量删除与清理上限。

批量管理提供独立“删除”按钮，选择事项后可用，删除前确认；取消确认不会删除。处理方式下拉框保留标记完成和暂停，删除不再重复放在下拉框中。

移动端批量提醒、应用消息和投递记录共用列表管理适配：选择框在前、单行列表、标题和操作固定，列表独立滚动。
