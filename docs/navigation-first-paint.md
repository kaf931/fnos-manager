# 主菜单首屏稳定性修复（2026-10-23）

## 原因

原始HTML的导航图标是空span，主JS执行后才使用多个React root异步填充；移动端“更多”容器初始为空，直到state、偏好及图标列表请求结束后才挂载触发按钮。图标和按钮的迟到会改变首屏布局。

## 修改

Vite的HTML转换阶段使用现有navigationIcon和icon公共图标目录生成菜单及设置SVG，同时输出移动端“更多”的初始触发按钮。运行时保留已有导航SVG，不清空重建；“更多”使用同步React提交接管触发按钮，避免空白中间帧。PC和移动端继续使用当前公共样式，不增加新图标或尺寸定义。构建与开发服务共用转换。

## 验证

首屏回归检查：五个菜单含最终SVG、设置图标存在、更多按钮含图标及菜单语义、HTML转换重复执行不重复插入。最终全量及NAS结果见下方。
