# NAS 管家 0.3.8

- 包含最新 RDP 安全模式与证书策略配置：自动协商、NLA、TLS、旧版 RDP；严格验证、首次信任并记住、忽略证书校验。
- 证书信任记录保存在应用数据目录，更新和重启后保留；已有连接保留原安全配置。
- 连接日志展示实际配置、原始状态码与具体失败原因，便于排查 TLS、认证和安全协商问题。

安装包：`NAS.-0.3.8-x86_64.fpk`、`NAS.-0.3.8-arm64.fpk`。发布标签使用 `0.3.8`，两个安装包同时上传至正式 Release。SHA-256 见随包校验文件。

- 修复旧版本的已完成更新任务挡住新版本“立即更新”的问题；历史完成记录不再显示为当前待刷新任务。
