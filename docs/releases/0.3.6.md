# NAS 管家 0.3.6

## 界面优化

- 修复移动端底部悬浮菜单在深色模式下的背景、边框、文字和选中态配色，统一使用公共主题变量。
- 发现新版本时，移动端“更多”显示红点，并在菜单内提供“应用更新”入口，可直接打开更新弹窗。
- “应用更新”的红点显示在文字后方，复用公共间距和徽章组件。
- 统一底部导航图标占位，避免红点出现时“更多”的图标及文字位置变化。
- 移除应用清理列表遗留的透明背景覆盖，与其他小屏详情列表统一卡片样式。

## 更新说明

包含此前的 GitHub Release 检查更新、按架构下载、断点续传、超时自动重试、更新缓存管理及安装失败回滚能力。

## 更新故障提示修复

- 安装前检查数据库兼容性，旧安装包支持的schema低于现有数据库时，明确说明版本差异并保留运行服务；回滚日志记录原始失败原因，界面展示具体原因与任务版本。
- 旧回滚任务不再将操作固定为“刷新应用”，允许检查并安装更高版本。
- 更新弹窗每30秒及页面重新获得焦点时刷新发布信息，新增“重新检查”；显式检查绕过本地短缓存。网络失败时保留已有发布信息与任务，使用旧缓存会明确提示。
- 829项完整回归、后续14项更新/策略测试与4项UI测试、构建及lint通过。NAS保留数据部署后仍运行0.3.3，数据库完整性ok、外键错误0、配置数量一致，登记未变。真机浏览器320px确认显示旧0.3.4数据库不兼容原因、最新0.3.6与“立即更新”，不再被旧回滚挡住。双架构包已重新生成并经更新器解包校验，需替换已发布的0.3.6旧附件。

发布附件统一命名为 `NAS.-0.3.6-x86_64.fpk` 与 `NAS.-0.3.6-arm64.fpk`；SHA256SUMS.txt已同步更新文件名，包内容保持不变。

## 2026-11-03 RDP 错误排查完善

- 握手前后均保留引擎原始错误码与说明，修复519被通用512覆盖的问题；对TLS/证书、DNS、NLA安全协商、认证、账号权限及目标拒绝连接提供基于原文的排查提示，未知原因明确标注，不凭状态码认定密码错误。
- 会话日志增加目标地址、端口、NLA模式、证书校验及请求桌面尺寸，不记录凭据。引擎错误原文限制长度并过滤密码和控制字符。
- 客户端接收并显示具体错误原因，后续通用断线不覆盖首个错误；“收到远程桌面更新”的过早提示改为客户端通道已建立、等待画面，不再暗示Windows登录成功。
- 服务日志同步记录JSON事件rdp_connection_failed，包含时间、会话编号、连接编号、阶段、状态码与具体原因。引擎没有提供原因时会明确说明；不包含底层FreeRDP全部调试跟踪。
- 837项完整回归及最终21项RDP定向测试通过，生产构建、lint、差异检查通过。NAS经SSH保留数据部署后运行0.3.6，关键接口正常、配置数量不变、数据库完整性ok、外键错误0，应用中心登记信息未变。
- 双架构0.3.6包重新生成并通过更新器解包及RDP诊断模块检查；校验文件已同步。未进行反馈者Windows设备的真机复现，当前NAS未配置该RDP目标。

反馈者需先安装包含本次修复的包，SSH执行下列命令，再复现一次连接失败并复制完整错误输出：

```sh
sudo tail -n 100 -f /var/apps/deskicons/var/service.log
```

也可直接在应用左侧“连接日志”复制本次会话日志。旧版本未记录的引擎具体原因无法事后恢复。
