# NAS 管家 0.3.5

## 新增

- 支持从 GitHub Release 检查新版本、查看 Markdown 更新说明，并匹配 x86_64 / ARM64 安装包。
- 支持应用内下载、校验和安装更新，展示下载百分比及安装状态；安装失败时恢复原运行文件与数据库。
- 新增手动 / 自动更新设置，自动更新在远程会话和后台任务空闲时执行。
- 更新下载支持断点续传，遇到连接超时、网络中断或服务器临时错误时自动重试，最多 5 次。
- 应用清理新增“更新缓存”，支持查看占用、更新日志和批量清理；进行中的任务受保护。
- 新增默认、靛蓝、鸢尾紫、深青强调色，以及终端条纹 / 纯色背景选项。

## 优化与修复

- 修复移动端底部悬浮导航深色模式配色：背景、边框、选中态与文字图标统一使用公共主题变量。

- 弹窗尺寸和滚动布局统一，检查更新时保持稳定尺寸，更新说明复用公共 Markdown 展示。
- 修复弹窗首次打开时关闭按钮出现蓝色焦点框的问题，保留键盘操作焦点。
- 修复飞牛应用软链接路径导致更新进程未执行的问题。
- 桌面左下角设置旁显示新版本入口及实际下载百分比；移动端“更多”显示新版本红点，展开后可通过“应用更新”直接打开更新弹窗。
- ARM64 安装包移除 1.2.0800 最低系统版本门槛；尚未完成 ARM 真机兼容性验证。

## 安装包

- `NAS管家-0.3.5-x86_64.fpk`
- `NAS管家-0.3.5-arm64.fpk`

请将两个 FPK 同时上传到 GitHub Release，标签使用 `0.3.5` 或 `v0.3.5`，并发布为正式版本。以上正文可作为发布说明，SHA-256 见随安装包提供的 `SHA256SUMS.txt`。

应用内更新保留应用数据并重启服务，当前远程连接会断开；通过 SSH 替换运行文件不会同步改变应用中心登记版本。
