# NAS 管家 0.3.7

## RDP 连接诊断

- 保留 RDP 引擎返回的原始状态码和具体错误说明，修复 519 被通用 512 覆盖的问题。
- 对 TLS/证书、DNS、NLA 安全协商、身份认证、账号权限和目标拒绝连接等错误提供对应排查提示；无法确定时明确说明，不直接判定密码错误。
- 连接日志补充目标地址、端口、安全模式、证书校验和桌面尺寸，不记录密码。
- 后续通用断线提示不再覆盖最初的具体错误。
- 修正过早显示“已收到远程桌面更新”的日志，区分客户端通道建立与 Windows 登录成功。
- 详细错误同步写入服务日志，事件名为 `rdp_connection_failed`，方便 SSH 排查。

遇到问题时，先执行下列命令，再复现一次连接失败，复制完整错误输出：

```sh
sudo tail -n 100 -f /var/apps/deskicons/var/service.log
```

也可在应用左侧“连接日志”中复制会话日志。旧版本没有记录的具体原因无法事后恢复。

### RDP 连接兼容性

- 新增安全模式：自动协商、NLA、TLS、旧版 RDP。
- 新增证书策略：严格验证、首次信任并记住、忽略证书校验；新连接默认严格验证。
- 首次信任的证书记录保存于应用数据目录，更新和重启后保留，证书变化时拒绝连接。
- 已有连接保留原安全配置，备份恢复包含新配置；日志展示实际安全模式和证书策略。
