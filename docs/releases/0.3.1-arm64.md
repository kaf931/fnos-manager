## 构建方式

```sh
TARGET_ARCH=arm64 npm run pack
```

ARM64 使用单独的 build/deskicons-arm64 目录，不清理或覆盖 build/deskicons 中的 x64 包。构建机仍用自身架构的官方 fnpack 生成 FPK；打进应用内、用于设备上生成桌面入口的 fnpack 则必须是 Linux ARM64。

跨平台安装运行依赖时禁用安装脚本，SSH 的可选原生加速器使用 JavaScript 回退，避免在 macOS 编译并混入主机原生模块。Sharp 和 libvips 使用 Linux ARM64 官方 npm 归档，验证 lockfile 中的 SHA-512，移除其他平台的 Sharp 可选二进制；打包前检查所有 .node/.so 及两个运行工具的 ELF 类别、字节序和 e_machine。
