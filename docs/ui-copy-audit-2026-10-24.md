# 全界面辅助文案检查（2026-10-24）

## 检查方法与边界

遍历 web 下的页面、弹窗、侧板和动态渲染模块，梳理 .help、.notice、small、选项副说明、空状态及动态状态文案（初始清单 112 处，包含元数据和运行状态，并非 112 条操作说明）。检查是否重复、是否连续堆叠说明、是否存在空节点间距；保留文件路径、容量、时间、错误和执行结果等有效数据。长路径与用户输入不按固定字数截断，以免丢失信息。

这是一轮全量源码与文案覆盖检查，浏览器复核覆盖下表所列代表路径；不把它描述为每种设备、每种异常状态的全量截图验收。

| 模块 | 已覆盖界面/组件 | 处理 |
| --- | --- | --- |
| 桌面图标 | 主列表、空状态、Docker 选择、自定义/管家入口、打开方式、图标上传 | 去除选项重复副说明；保留打开失败的简短指引 |
| 计划任务 | 主列表/卡片、新增/编辑、类型说明、设备选择、手动执行预览、日志/历史、飞牛授权 | 执行身份去重；重试补跑规则折叠；保留实际影响与权限提示 |

| 公共界面 | 确认弹窗、加载/空状态、表单和底部面板、菜单/卡片元数据 | 公共段落小字统一行高 1.6、上距 8px，空段落隐藏；说明折叠复用同一份公共样式 |
