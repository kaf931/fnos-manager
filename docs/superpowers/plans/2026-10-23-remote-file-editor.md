# SSH 在线编辑实施计划

用户已确认在线编辑方案并要求实施。复用现有会话所属用户鉴权、SFTP 通道和公共弹窗。参考 CodeMirror 官方文档、宝塔文件读写 API、Cockpit 文件版本检查。

- [x] 增加独立文本编解码及 SFTP 读写模块；10 MiB 限制、普通文件检查、内容版本冲突、同目录临时文件原子替换、保留权限与所有者；服务不支持原子替换时不降级为先清空文件。
- [x] 增加 Nest DTO 与接口，复用 connectedOwned 校验；正文仅在请求和内存中，不落库、不发 AI。
- [x] 按需加载 CodeMirror 公共弹窗，右键入口、编码选择、行号高亮查找、保存快捷键、关闭未保存提醒、断开连接禁止保存。
- [x] 回归覆盖编码、二进制/超限拒绝、冲突不覆盖、失败清理、写回完整性；执行类型/规范/构建检查。
- [x] SSH 部署并验收版本、服务、数据库、接口，记录结果，保留用户数据。

范围：UTF-8、UTF-8 BOM、UTF-16LE/BE（BOM 自动识别），GBK/GB18030 手动指定。只读可查看；无扩展名文本可打开；不提供二进制/Office 编辑。编辑文件不执行。通用 SFTP 不提供跨外部进程的 compare-and-swap，保存前版本检查降低冲突风险，但不声称消除外部并发写入竞争。
