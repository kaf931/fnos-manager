# RDP integration implementation plan

Goal: Add native RDP to the existing remote connection workspace without Docker or another UI style system.

Approved architecture: React + Guacamole browser client → existing authenticated NestJS WebSocket gateway → loopback-only guacd/FreeRDP. Existing SSH and VNC remain intact. SQLite stores owner-scoped RDP configuration. No credentials in URLs or diagnostic logs. Default NLA and certificate verification. Native dependencies must be packaged for x86_64 and arm64, with licenses.
