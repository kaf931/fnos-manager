# 通知中心、提醒事项与菜单稳定性 Implementation Plan

**Goal:** 将消息通知扩展为通知中心，支持记事／待办、一次及日周月提醒，复用通知模板；修复菜单闪烁，更新 NAS 后提交推送。

**Architecture:** SQLite 持久化提醒与模板关联，调度器将到期提醒与下次时间在同一事务写入通知投递队列。复用已有队列、渠道、重试、历史保留与应用清理。时间沿用项目计划任务的北京时间；月末按目标月最后一天提醒，后续仍按原始日期计算。页面保持挂载并缓存筛选与数据，布局标记在绘制前同步。

**Tech Stack:** React、Semi Design 公共标签、公共列表／卡片／弹窗／开关、NestJS、SQLite、现有通知投递器。

## 约束

- 两个标签：通知模板、提醒事项。不新增页面专用样式，保留已有模板、记录和 NAS 数据。
- 提醒可无时间保存为记事；启用通知必须有时间与可用模板。完成、暂停、延期15分钟、重新打开、编辑与删除按账号隔离。
- 多模板分别投递、事件去重；重启补发一次，不堆积重放错过的重复提醒。提醒修改、暂停、完成、删除取消其未发送通知。
- 提醒投递复用应用清理投递记录与现有上限；账号提醒事项最多500条。正文不写运行日志。
- 版本保持0.4.2，不重打包。验证后使用既有 SSH 停止／替换／启动流程，保留数据，再提交推送 origin，作者使用 kaf931。
