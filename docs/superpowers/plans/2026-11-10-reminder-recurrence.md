# 提醒事项重复规则扩展

按用户要求新增中国大陆法定工作日、法定节假日及自定义周几。使用既有表单、多选框、卡片与北京时间调度。自定义至少一个周几，UI 周一至周日，持久化使用 JS weekday 0=周日。修改周几必须重新计算下次提醒。

日历使用 holiday-cn（MIT、附国务院公告出处）的 2026/2027 数据并本地缓存；法定工作日排除放假、包含补班，法定节假日匹配公告放假日期，普通周末不等同节假日。后台有启用的日历提醒时定期获取更新，缓存失败不破坏可用数据。缺失年份明确报错；运行中跨入未知年份时保持提醒启用并等待日历，更新后恢复计算，不能猜测或无限重复投递。

1. 扩展 domain、DTO、数据库版本 35：重建受 repeat CHECK 限制的 reminders，新增 weekdays JSON，保留旧记录、投递关系与索引；旧记录 weekdays=[]。
2. 先写调度、迁移、仓库、DTO/UI 回归测试，覆盖调休补班、普通周末、指定首日不匹配、多个周几、跨年缺数据及恢复、暂停/重启/去重、修改周几重新排程。
3. 实现纯调度函数、受限来源日历解析/缓存/更新服务及通知服务生命周期集成，防止更新阻塞通知发送或关闭后写库。
4. 提醒表单增加选项和公共周几多选，列表展示所选周几，保持已完成事项不重新启用。
5. 运行全量测试、类型检查、lint、构建；浏览器窄屏操作检查，保存 QA。保留数据 SSH 更新 NAS，确认版本、schema35、完整性/外键、原配置和接口，提交推送。

通知中心交互同步：批量管理增加独立删除按钮并移除下拉框中的重复删除入口；模板更多按钮在开关左侧，开关靠右；五个品牌渠道使用本地官方标识，通用渠道使用共享图标。回归覆盖确认、取消、禁用和按钮顺序，并按现有 NAS 数据保留流程验收。
