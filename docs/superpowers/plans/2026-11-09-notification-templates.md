# 通知模板与邮箱 Implementation Plan

**Goal:** 将单一通知表单改为可独立启用的多通知模板列表，加入 SMTP 邮箱。

**Architecture:** 模板拥有独立 ID、名称、配置和修订号；队列按账号、事件和模板去重。旧配置迁移为默认模板，保留历史投递；删除或修改模板只影响该模板的未发送任务。SMTP 使用 Nodemailer，复用通知消息变量与摘要，不接收任意邮件对象。

**Tech Stack:** React、Semi Design 公共控件、NestJS、SQLite、Nodemailer。

## 约束

- 列表、筛选、空态、公共弹窗、卡片和开关参考计划任务／网络唤醒；不新增专用 CSS。
- SMTP 支持 TLS、STARTTLS 和显式无加密，默认 STARTTLS；默认验证证书。不输出凭据及原始服务器错误。
- 更新 NAS 保留数据，SSH 停止／替换／启动，不改版本号，不重新打 FPK。
