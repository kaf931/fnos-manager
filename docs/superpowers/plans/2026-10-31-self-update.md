# 一键更新实施计划

授权范围：用户点击立即更新后自动下载、显示进度、校验、保留数据更新并重启。保留 SSH 更新语义，不调用 appcenter-cli install-local，不卸载；应用中心登记版本保持原值。

- 扩展 Release 附件元信息，读取 GitHub SHA-256，只有有新版且匹配架构/校验值时允许更新。
- backend/updates：独立更新进程、状态文件、受限下载及安全解包，核对 manifest 和包内版本/架构。
- 更新进程复制至数据目录，不依赖将被替换的运行代码。停止服务后备份运行目录与 SQLite，替换运行文件后启动；校验版本、关键接口及数据库完整性，失败恢复旧代码与 SQLite。
- Nest 接口不接收客户端 URL/路径/命令，管理员/CSRF 校验沿用公共网关；开发环境不执行更新。
- 前端复用公共弹窗、按钮及进度组件；当前版本不显示立即更新，更新中显示阶段和实际下载进度，重启后恢复进度与完成提示。
- 测试版本/架构/校验、越界归档、并发、网络错误、替换失败回滚和界面状态；NAS 只验证已有版本不可触发更新，不用 GitHub 旧包覆盖当前未发布代码。

结果：独立模拟服务已验证完整下载、SHA-256、安全解包、替换、重启、版本与接口/SQLite验收；失败回滚及凭据保持通过。804项完整测试通过。NAS当前0.3.4与最新Release相同，只验证更新能力可用与同版本拦截，没有执行正式跨版本升级。桌面端有新版提示位于设置左侧，移动端底部菜单未变。
