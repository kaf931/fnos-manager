# 全量前端类型与渲染统一

目标：落实用户要求，将前端所有业务模块纳入TypeScript strict，动态UI采用React；原生DOM仅作为显式适配边界。保留现有接口、用户数据、菜单与样式。

## 统一约束

- web业务源码只允许.ts/.tsx，allowJs=false；strict=true，不允许any、@ts-ignore、@ts-nocheck或按功能排除文件。
- 请求返回、会话、设备、存储、任务及表单props具有显式结构类型；未知外部输入在边界收窄。类型断言只能用于明确的DOM/第三方边界，不能代替业务模型。
- React负责动态UI节点；原生DOM用于浏览器API、焦点/布局测量、xterm及静态宿主对接。不得同时由React及手动DOM写同一片子树。
- 全量迁移后移除旧JS源码，不保留兼容实现。测试使用独立编译产物，不把旧JS留在web内。
- SDK、表单、确认弹窗、选择组件及API请求采用公共类型边界，保留已有公共CSS和移动端触摸/安全区行为。
