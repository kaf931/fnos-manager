# ADB Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在现有远程连接中提供 ADB 和侧栏功能。
**Architecture:** NestJS 管理应用专属 ADB server 和设备会话，浏览器通过已认证 API/WebSocket 操作。Tango 提供 ADB/scrcpy 协议和解码能力。
**Tech Stack:** React, NestJS, SQLite, Google ADB, Tango, scrcpy.
**Spec:** docs/superpowers/specs/2026-11-07-adb-design.md

## Global Constraints
- 公共 UI、用户隔离、数据保留；不覆盖工作区已有修改。
- 依赖覆盖 Linux x86_64/ARM64；不要借用用户的全局 adb server。
- 不记录配对码、ADB 私钥。

## Review Focus
- 错误配对码与未授权设备：明确错误，保留重试。
- 断开/关闭：终止 socket、子进程、临时文件和视频流。
- 路径/命令参数：使用参数数组，禁止 shell 拼接。
- 无权限文件/超大上传：明确失败并清理临时数据。
- 菜单和标签切换：只选中会话输出，避免迟到响应污染。
