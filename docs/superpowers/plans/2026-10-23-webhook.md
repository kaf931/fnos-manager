# Webhook 通知 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development; preserve existing uncommitted work.

**Goal:** 完成任务和扫描异常的可靠通知、配置及记录。
**Architecture:** Nest 通知模块、SQLite repository/outbox、独立有界发送 worker，任务/扫描完成事务中 enqueue。
**Tech Stack:** TypeScript strict, NestJS, SQLite, React, shared UI.
**Spec:** docs/superpowers/specs/2026-10-23-webhook-design.md

## Global Constraints
- 当前目录继续实施，不提交、不清空数据；验证后 SSH 部署。
- 默认不发送通知；不向真实外部地址做测试，不运行重启关机。
- 设置与记录按账号隔离，HTTP 鉴权与 CSRF 沿用现有实现。
- 超时 10 秒、最多尝试 3 次，间隔 30/120 秒，终态记录每账号 200。

## Review Focus
- 重启后恢复队列，不重复运行任务；网络延迟时不重复领取。
- 目标变更取消旧待处理，不把旧事件发送到新地址。
- 事件载荷不泄露凭据、脚本、输出、路径、原始错误。
- 历史迁移保留旧数据，启动不追发已有历史。
- 无效 URL、错误状态、账号隔离、CSRF 和关闭生命周期。
