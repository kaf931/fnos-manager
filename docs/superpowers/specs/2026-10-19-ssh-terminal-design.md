# SSH 终端设计规格

状态：书面规格和实施计划已确认；当前会话直接实施。日期：2026-10-19。

## 目标与边界

在 NAS 工具箱中增加“SSH 终端”菜单，让管理员从飞牛网页或手机 App 连接 NAS 本机及其他 SSH 主机。导航、筛选、表单、按钮、卡片、主题和移动适配沿用现有应用。

“本机”指运行应用的 NAS，不是访问页面的手机或电脑。本机也通过 SSH 登录，端口可配置、默认 22；使用填写的 SSH 账号权限，不因应用进程以 root 运行而提供免登录 root Shell。NAS 现有非标准 SSH 端口可以在连接表单中填写，不硬编码会话中的地址、用户名或密码。

首版包含连接配置的增删改查、密码或私钥认证、主机指纹确认、交互式终端、断开、重连、清屏和移动辅助按键。首版不包含 SFTP、跳板机、端口转发、命令历史归档、后台持久会话、自动重连和凭据持久保存。

## 官方能力与开源依据

2026-10-19 查阅飞牛完整公开文档，未发现直接创建 SSH 会话或系统终端的开放 API。统一网关明确支持 WebSocket，并在握手时传递登录用户身份；终端协议和 SSH 客户端由应用实现。统一网关文档：https://developer.fnnas.com/docs/core-concepts/gateway-registration 。完整索引：https://developer.fnnas.com/llms-full.txt 。

推荐组合为 xterm.js（前端终端）、ssh2（服务端 SSH）和 ws（WebSocket）。WebSSH2、WeTTY 用于参考连接生命周期和终端交互。相比嵌入完整第三方终端，直接集成可复用当前样式、认证和打包方式；相比本地 node-pty Shell，统一 SSH 登录可保持本机和远程行为一致，并避免引入本地原生编译依赖。

来源：

- https://github.com/mscdex/ssh2
- https://github.com/billchurch/webssh2
- https://github.com/butlerx/wetty

以上为接入方式选择，不代表飞牛认证了这些组件或提供了 SSH UI 规范。借用开源代码时保留对应许可证；新增依赖记录具体版本。

## 页面与交互

导航新增第三项“SSH 终端”，配终端线性图标。标题仅为菜单名称。现有两菜单的搜索宽度、顶部面板间距、桌面分页、移动底部安全区和键盘时隐藏导航行为保留。

未连接时显示连接配置列表：顶部搜索连接名称、地址或用户名，类型筛选为全部、本机、远程，右侧新增连接。桌面使用当前卡片视觉；移动复用卡片尺寸、圆角、间距及右上角更多按钮。移动新增入口只显示图标，不增加刷新按钮；配置列表可下拉刷新。

连接表单字段：名称、类型、本机或远程地址、SSH 端口、用户名。创建和编辑只保存这些非凭据配置。点击连接后选择密码或私钥认证，私钥可粘贴或从本地文本文件读取，加密私钥可输入口令。密码、私钥及口令仅用于此次连接。默认不自动聚焦，不把凭据放入 URL、localStorage 或连接配置。

桌面表单复用当前对话框，移动复用 openEditorSurface 的普通页面编辑布局，不恢复额外键盘避让。选择私钥文件不会触发上传到其他服务，只发送给本应用后端用于 SSH 认证。

首次连接显示目标地址、端口、主机密钥算法和 SHA-256 指纹，用户接受后才能发送 SSH 认证凭据。已信任主机密钥变化时阻止连接，明确展示新旧指纹，用户单独选择替换信任后才能重试。取消或超时结束待验证连接。

终端页在同一菜单内展示，工具栏包含连接名称、目标与状态、返回列表、断开或重连、清屏。终端占据剩余区域，跟随浅色或深色主题；仅终端内容使用等宽字体。断开使用现有错误色样式。清屏仅清理本次显示缓冲区，不向目标发送清理命令。

首版同时只允许一个活动终端会话：切换其他菜单保留连接和终端实例；返回列表可继续当前会话。连接其他配置前明确提示关闭当前会话。编辑或删除正在使用的配置前先处理当前会话，不静默切换目标。

移动端终端提供 Esc、Tab、Ctrl、方向键辅助栏，按钮沿用现有触控尺寸。终端区域不启用下拉刷新，避免与滚屏、鼠标报告冲突。通过容器 ResizeObserver 计算终端列行并通知 SSH PTY，不调整页面键盘高度或主动滚动输入框。实体手机中文输入和键盘动画需实机复测，不以桌面视口模拟替代。

## 模块与数据归属

服务端拆分为连接配置存储、主机信任、会话管理、HTTP 路由和 WebSocket 接入模块，置于 server/terminal/。ssh2 只在会话模块中使用；HTTP 和 WebSocket 共享会话生命周期和用户归属校验。

前端新增终端菜单模块和终端视图模块。新增小型统一导航管理器，由它控制三个页面和激活事件；任务模块不再对所有导航按钮绑定二选一的页面切换。平台 SDK 标题从当前菜单定义读取。仅重构此导航耦合，不改动任务执行、图标安装逻辑。

生产环境使用网关提供的 X-Trim-Userid 作为所有权标识，要求 X-Trim-Isadmin 为 true，拒绝缺失或非法 UID。不同管理员不能读取对方连接或使用对方会话。本地开发模式使用独立 development 所有者，仅监听回环地址，不提供生产鉴权降级。

数据文件位于应用 dataDir/terminal/，目录权限 0700、文件权限 0600，原子替换写入。存储结构包括：
- connections.json：版本及连接列表，每项包含随机 ID、ownerUid、name、kind、host、port、username、createdAt、updatedAt。
- known-hosts.json：按 ownerUid、规范化 host、port、密钥算法记录已接受的公钥及 SHA-256 指纹。

凭据、会话票据和终端内容不写入上述文件、服务日志或应用执行记录。远程连接从 NAS 发起，不支持 URL、代理参数或任意 Shell 参数作为主机地址。

## 传输与鉴权

继续使用现有 /app/deskicons 网关和 app.sock，不新增公网监听端口。WebSocket 路径为 /app/deskicons/terminal/ws。

新增 HTTP API 统一放在 /app/deskicons/api/terminal 下：
- GET/POST connections，PUT/DELETE connections/:id：当前所有者的连接配置。
- POST sessions：使用已有连接 ID 创建待连接会话，返回一次性短期握手票据；不接收凭据。
- DELETE sessions/:id：主动关闭当前用户会话。

所有修改接口沿用现有 CSRF 校验。WebSocket upgrade 不经过 Express 普通中间件，必须单独检查固定路径、管理员身份、UID 和来源；不能误以为当前 app.use 自动保护 upgrade。

票据绑定用户和会话，仅在内存保存摘要，30 秒过期、成功使用即作废。通过同源 WebSocket 首条认证消息传递，避免放 URL；5 秒未认证即关闭。网关模式还需验证握手用户与票据所有者相同。限制握手频率、消息大小和每用户会话数量。

Origin 必须匹配当前公开请求来源；如网关保留外部 Host 或转发主机头的行为与预期不同，先在 NAS 验证并采用受信任网关提供的来源，不能简单允许任意 Origin。浏览器经 HTTPS 访问时使用 WSS；HTTP 访问沿用网关现状，界面连接说明提示凭据经网页连接传输，建议使用 HTTPS。

数据流：HTTP 创建会话 → WebSocket 验证票据和身份 → ssh2 建立握手 → 校验主机公钥 → 必要时请求用户确认 → 确认成功后请求此次凭据 → SSH 认证 → 创建交互式 PTY → 双向传输。

客户端消息限制为 authenticate、trust-host、credentials、input、resize、disconnect。服务端发送 state、host-key、credentials-required、output、error。每种消息校验结构、长度和会话状态。input 只允许连接成功后写入 SSH Shell 流；resize 限制合理行列范围。凭据不进入错误详情。

认证阶段通过 ssh2 支持的异步认证机制在主机确认后取得凭据；实现时验证调用顺序，不使用跳过 hostVerifier 的方式简化连接。

## 生命周期与错误

状态为待验证网页会话、连接中、等待主机确认、等待凭据、SSH 认证中、已连接、已断开或失败。前端根据状态禁用重复操作并展示明确结果。

SSH 连接和等待凭据或指纹确认均有超时；SSH 保活用于发现网络断开。网页 WebSocket 断开即关闭 SSH 流及客户端；退出页面不承诺后台命令继续运行。切换应用内菜单不销毁 WebSocket。服务退出时关闭全部终端会话，再关闭现有计划任务引擎。

输出采用有界缓冲和背压；限制终端回滚行数、单消息长度及待发送字节数。慢客户端超过上限时终止会话并提示重新连接，避免输出堆积耗尽内存。不自动执行重连或重放命令，以免操作重复。

错误区分 DNS、连接被拒绝、连接超时、认证失败、私钥无效、主机密钥变更、页面会话过期和远端退出。服务日志仅包含事件类型、会话 ID 与必要错误代码，不记录输入输出或密钥材料。

## 验收与发布

1. 单元测试覆盖配置校验、用户隔离、原子存储、票据过期与单次使用、主机信任变化、协议状态限制和连接清理。
2. 用隔离 SSH 测试服务覆盖密码、私钥及加密私钥认证、PTY 输入输出与 resize、超时和网络断开，不执行重启、清理或现有计划任务。
3. HTTP 与 WebSocket 测试拒绝未认证、非管理员、伪造所有者、错误票据、来源不匹配和超限消息；确认凭据不出现在文件和响应错误中。
4. 浏览器检查桌面及移动三菜单切换、表单关闭、搜索筛选、主题、更多菜单、终端布局和辅助键；保持现有图标和计划任务行为。
5. NAS 验证现有统一网关能完成 WebSocket upgrade 并传递用户身份；使用用户授权的现有 SSH 账号验证本机连接，仅执行 whoami、pwd 等只读命令后断开。远程目标以隔离测试 SSH 服务验证，未提供实际远程服务器时不声称已通过真实公网连接。
6. 正式版本号升级为 0.2.8，并让 /state、package.json、打包清单一致；运行时包必须包含 ssh2 与 ws，前端终端按菜单懒加载。
7. 发布前备份现有应用和真实数据目录，使用官方应用管理流程完成更新；验证 running、菜单、静态资源与后端版本，保留回滚材料。首次上线连接列表为空，不迁移聊天凭据。
