# SSH 终端文件面板设计

日期：2026-10-19。状态：设计及实施计划已确认，0.2.9 已实现并部署 NAS，验证见 docs/verification.md。

## 用户需求与范围

用户希望连接后继续全屏显示终端，在右侧边缘垂直居中放置展开/收起按钮，展开显示类似参考图片的可视化文件管理。已确认第一版包含：浏览目录、上传、下载、新建文件夹、重命名、删除。

保留现有连接配置、保存认证、主机信任、终端灰白交替行、全屏隐藏导航和手机安全区行为。文件属于当前连接的目标主机，由该 SSH 账号权限决定可见和可修改范围；NAS 本机和远程连接使用相同流程。

## 方案选择

采用现有 ssh2 Client 的 SFTP 子通道，复用已登录且核验主机指纹的连接。相比新建第二条 SSH 连接，无需重复认证，连接目标和文件归属一致。相比执行 ls、cp、rm 等 Shell 命令，不需要拼接命令或解析终端输出，文件名和路径作为 SFTP 参数传递。

依据：https://github.com/mscdex/ssh2#client-methods 与 https://github.com/mscdex/ssh2/blob/master/SFTP.md 。沿用当前 ssh2 依赖，不引入独立文件管理服务，也不增加网络监听端口。

## 界面与布局

默认收起。桌面端在终端内容区域右侧居中显示窄型箭头按钮，提供“展开文件管理”提示及 aria-expanded。展开后终端在左、文件面板在右，按钮移至二者分界处，箭头反向并显示“收起文件管理”提示。按钮不挡住顶部断开操作。面板默认宽360px，受可用宽度约束；终端通过现有 ResizeObserver 重新计算列数，不重新建立 SSH 会话。

面板头部显示“文件管理”及关闭操作。下方工具行包含上一级、刷新、可编辑的绝对路径，输入后回车跳转。操作行提供上传、新建文件夹及文件夹/文件数量。内容表格列为名称、修改时间、类型、大小与更多操作，目录排在文件前，可按名称、时间、大小排序；目录点击进入，文件通过更多菜单下载。名称单行省略并保留完整提示；长路径不会挤压工具按钮。表头固定、内容独立滚动，不增加分页组件。

样式使用项目现有的表格、按钮、输入框、菜单、确认对话框、圆角及滚动条规则，浅深主题均适配。文件夹、普通文件和链接使用现有 SVG 图标体系，文件名使用普通界面字体，不套终端等宽样式。

移动端面板展开后覆盖终端内容区，占满可用宽度，保留顶部连接工具栏及收起入口；文件列表改为名称、时间、大小的紧凑行，操作放入更多菜单。面板底部留系统安全区。关闭后终端原会话和滚动状态保留。路径输入使用正常页面滚动和 App 自身键盘行为，不新增 visualViewport 或键盘高度监听。

## 文件操作

首次展开才初始化 SFTP，读取 realpath('.') 作为起始目录。之后独立记录面板路径；第一版不解析 Shell 当前目录，也不向终端注入 cd 命令。切换目标或重连后重置路径和列表，收起再展开保留当前目录并刷新。

浏览目录时显示加载态、空目录及可重试错误。权限不足或目标不支持 SFTP 时仅在面板显示具体说明，不断开可用终端。符号链接标识为链接，点击时通过远端 stat 判定能否进入目录；下载只允许解析为普通文件的目标，不读取设备、FIFO 或 socket。

上传通过统一样式按钮选择本地文件，多文件串行传输，显示当前文件、进度及取消。采用 HTTP 二进制流到 SFTP 写入，禁止将文件转为 JSON/base64 或全量缓存在内存。首版单文件上限256MiB，选择前和服务端同时检查，超限明确提示。先写入目标目录随机临时文件，完成后提交为目标名；取消、失败清理本次临时文件，断线无法清理时在结果中提示。重名默认阻止并允许修改上传名称，第一版不覆盖已有文件。提交使用目标支持的无覆盖语义，不能保证时失败并保留原文件，不回退为覆盖写。

下载通过有所有者校验的会话 HTTP 路由流式输出，并生成安全的 Content-Disposition 文件名。不把凭据、服务器本地文件路径或用户文件内容写入日志。显示下载已发起，浏览器负责本地下载进度；不声称浏览器下载完成。

新建文件夹和重命名使用现有输入弹窗，名称为单个路径分量，禁止空值、.、..、斜杠、NUL 和控制字符。目录跳转允许有效绝对路径及上一级，访问范围由远端 SSH 账号权限决定，不人为限制在初始目录。重命名遇到已存在目标时拒绝，不静默覆盖；优先使用无覆盖操作语义，不提供不安全的覆盖回退。

删除前显示目标名称和“无法撤销”的确认。首版支持文件、符号链接、空目录；非空目录拒绝删除并提示，不递归清空。删除链接只删除链接自身，不遍历其目标。上传、删除、新建和重命名成功后刷新当前列表，不发送 Shell 命令。

## 接入与生命周期

新增 server/terminal/files.js 封装 SFTP 初始化、路径/名称校验、目录元数据、传输和文件操作；TerminalSession 持有子通道，TerminalService 提供按 ownerUid 和会话 ID 查找已连接会话的方法。HTTP 路由始终检查管理员身份、会话归属和已连接状态，写操作继续使用现有 CSRF 校验；传输路由不会放宽当前网关鉴权。

接口位于 /terminal/sessions/:id/files，列表、下载使用 GET，上传、创建目录、重命名、删除使用独立写请求。二进制上传保持流式，不安装全局原始请求体缓冲中间件。请求不接受覆盖连接目标或凭据参数；只能操作当前已认证会话的目标。

每会话最多一个进行中的写操作和两个下载流，目录查询带超时、并发和返回条目上限（10000）；超限提示缩小目录范围，不静默截断。目录采用 SFTP opendir/readdir 分批读取，提前停止并关闭句柄。传输使用流背压，不进入终端 WebSocket 的输出确认队列。客户端取消、请求中断、会话断开会销毁相关流、句柄和临时资源。收起面板不强制中断用户已启动的传输。

前端新增 web/terminal-files.js，负责面板、目录列表、路径、操作弹窗与传输状态；terminal-view.js 仅传递当前会话和连接状态，连接关闭时清除旧列表与操作能力。请求绑定会话代次，迟到响应不能覆盖新连接的数据。返回连接列表或切换菜单时不销毁仍然有效的终端会话。

## 验收与部署

先在隔离 SSH/SFTP 测试服务验证浏览、权限拒绝、空目录、链接、Unicode/特殊字符名称、上传下载内容一致、创建/重命名/删除、重名保护、非空目录拒删、超限、取消、断线清理、超时、用户隔离和旧会话拒绝。回归现有全部 SSH、图标与任务测试。

浏览器检查桌面展开/收起、贴边居中、终端重新适配、移动覆盖布局、安全区、菜单与上传控件样式；不以桌面模拟替代实体手机键盘实测。

部署前备份 NAS target 与 appdata。后端更新通过官方管理器停止和启动工具箱，会结束工具箱当前 SSH 会话。NAS验证优先只读浏览，写操作只在明确创建的专用临时测试目录进行，不对用户既有文件执行删除或覆盖；测试结果写入验证文档。真实远程主机未提供时，远程能力以隔离测试为准。
