# 统一操作记录

承接已确认路线第3项。系统设置增加操作记录入口，公共弹窗/表格/分页，按动作和结果筛选。每账号只可查看自己的记录，显示操作者账号 ID、动作、目标摘要、开始/结束时间、结果。默认每账号保留1000条，设置允许100/500/1000/5000条；只修剪已结束记录，进行中的操作保留。没有手动清空接口。

SQLite schema16增加 operation_records 和 operation_settings。STRICT、主键非空、枚举CHECK、owner/time索引。每次实际操作先登记 running，再结束为success/partial/failed/interrupted。应用重启将残留running标记interrupted，不宣称外部操作是否成功；不得因为写记录失败自动重做实际动作。回执重试不重复记录配置恢复。SQL事务内配置恢复及记录原子提交；外部文件/电源操作登记在前，最终记录失败不能把已经成功的动作误报为可重试失败。

覆盖：SSH文件管理删除/改名；存储批量改名及撤销、重复文件删除/移动；配置合并恢复；网络唤醒设备的重启/关机（含计划任务调用）；AI 审核或静默执行的命令及技能动作。普通任务运行已有历史，不重复记录为AI；文件读取、下载及聊天生成不记录。未通过账号或参数校验的请求不记录成实际操作，避免伪造其他账号目标。

摘要使用受控字段：文件操作仅文件名或数量，不存完整目录路径；设备显示配置名称，不存主机地址、密码；AI只显示动作类型及连接/会话标识，不保存命令、参数、输出、对话文本；恢复显示导入/跳过数量。错误为固定摘要，不写入原始异常。目标自由名称截断120字并除控制字符。记录保存在本地，不发送Webhook，不纳入配置备份。

实现采用独立 repository/service 和业务执行点显式调用，相比 HTTP 统一拦截器能够覆盖后台任务与AI静默执行，且避免请求成功但实际异步失败被记为成功。代码遵循现有Nest模块/controller/dto/service边界。测试不执行真实电源操作；部署保留数据。
