# 远程连接集成设计

用户最终确认仅增加 VNC，将 SSH 终端菜单改为远程连接；统一连接列表、按 SSH/VNC 筛选，新增表单按协议显示字段，详情多标签全屏，保留 SSH 功能与独立桌面入口 key terminal。

采用官方 noVNC RFB 客户端 + NestJS 鉴权 WebSocket/TCP 转发，浏览器解码画面与处理键鼠。没有 guacd、RDP、Docker 运行依赖，不引入其他管理后台。参考 noVNC API 和 websockify 的二进制转发架构。

SSH 表及连接行为保持；新增严格关系表 vnc_connections 保存主机、端口、可选用户名/密码，按用户隔离并引用现有资产目录。VNC 配置不能被选作设备电源 SSH 或 AI SSH。凭据不放 URL；仅一次性短票据用于同用户同来源的 WebSocket 升级，后端固定目标地址，不能从 WebSocket 指定任意主机。限制会话数、消息大小、缓冲、建立连接超时并清理关闭。

VNC 工作区共用标签和资产目录，仅显示适用工具：画面适应/实际大小、剪贴板、特殊按键、移动端输入。复用公共按钮、弹窗、底部面板和间距。服务器须启用 VNC，连接由 NAS 发起；SSH 文件管理与 AI 不自动附加到 VNC。

不启动先前下载的 guacd 镜像；移除本地未完成的 Guacamole 实现。通过 SSH 停止替换启动部署，保留现有数据。
