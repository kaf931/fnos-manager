# 桌面图标设计

用户已确认开始开发，仅包含桌面快捷图标功能。管理页面支持 Docker 选择、名称和地址识别、图标自动获取、上传覆盖、创建编辑删除和桌面预览。

官方明确规范：应用入口使用 app/ui/config 的 .url；64 和 256 像素 PNG 图标，sRGB，小于 1024 KB，圆角主体与留白；统一网关提供管理入口；SDK 读取主题，micro_app=true。页面字号、色值和间距属于参照系统设计，不宣称为官方设计 token。

Node.js 后端通过 Unix Socket 调用 Docker 只读查询接口。优先读取容器标签图标，之后尝试应用网页 favicon；多端口交给用户选择。仅接受 HTTP(S) 地址，不执行容器命令。图标经过解码、尺寸与体积限制及重新编码。数据原子持久化。

桌面接入不修改飞牛系统页面。生成独立快捷方式应用包，使用官方 CGI 入口跳转目标服务；通过官方 appcenter-cli 安装入口包。保存操作只持久化，用户点击添加或更新才执行安装；删除只卸载本应用生成的独立入口。系统界面刷新由飞牛自身处理，必要时提示刷新。

本机默认仅监听回环地址。部署到 fnOS 时使用统一网关 Unix Socket，以网关校验过的管理员身份和页面会话令牌使用管理 API。实机确认 Docker Socket 与 appcenter-cli 需特权，因此原生包声明 root 权限，仅在 Unix Socket 提供服务。不开启无鉴权 TCP 监听，不提供通用命令执行接口。

验证覆盖容器端口和标签识别、非法地址、持久化、图标规格、入口包生成、API CRUD。实际 fnOS 安装与主题联动依赖测试设备。
