# ADB 远程连接

按用户已选择的 Tango/ya-webadb + NAS 后端中转方案实现，在远程连接协议中增加 ADB。复用现有卡片、资产目录、多标签、工作区侧栏、文件列表、公共弹窗和连接日志；不添加独立视觉系统。

连接配置包含名称、主机、端口、资产目录。通过 NAS 管理的 ADB server 连接网络调试设备；支持配对码无线调试及 NAS USB 设备。私钥保存在应用数据受限目录，不能进入日志或响应。ADB server 仅在回环监听。按用户隔离配置和会话，不允许任意远程用户操作其他用户会话。

侧栏固定功能：资产、投屏、终端、文件、应用安装、设备信息、传输、日志。投屏使用 scrcpy，支持触控、键盘、返回/主页/最近任务及全屏。日志仅当前会话，含连接阶段和明确失败原因。传输应有限流、取消和大小保护。Android 权限仍以 adbd 授权为准，不承诺 root 目录访问。

实现兼顾 x86_64/ARM64；无法支持的运行环境要明确报错，不把缺失依赖当作连接超时。自动化测试覆盖授权隔离、输入校验、生命周期、失败清理和 UI 菜单。真机条件尚待用户答复，不得宣称未执行的真机测试通过。

备选 ws-scrcpy 作为交互参考；选择 Tango 库以便接入现有 React/NestJS，而非嵌入另一个完整应用。
