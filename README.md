# NAS 管家

NAS 管家是面向飞牛 fnOS 的工具，集中管理桌面图标、计划任务、SSH 终端、存储和网络唤醒。支持桌面端和移动端，也可以把单个功能添加到飞牛桌面。

## 常用功能

| 菜单         | 它能帮你做什么                                     | 一个常见场景                         |
| :----------- | :------------------------------------------------- | :----------------------------------- |
| **桌面图标** | 给 Docker、自定义链接及 NAS 管家菜单创建桌面入口   | 把常用服务放到桌面，少记几个端口     |
| **计划任务** | 定时启停程序、控制容器、运行脚本，联动网络设备     | 工作日前唤醒电脑，夜间执行维护脚本   |
| **SSH 终端** | 多标签连接、文件管理、常用命令、监控与 AI / Skills | 一边查看资源，一边通过终端处理问题   |
| **存储管理** | 分析空间、查重、批量改名、记录与 AI 附件清理       | 找出大文件，整理重复照片和杂乱文件名 |
| **网络唤醒** | 扫描局域网、批量添加设备、唤醒与 SSH 电源控制      | 用一直在线的 NAS 唤醒局域网电脑      |

## 下载安装

在 [GitHub Releases](https://github.com/kaf931/fnos-manager/releases) 下载与设备架构匹配的 `.fpk` 安装包，然后在飞牛应用中心选择 **手动安装**。安装后，从飞牛桌面打开 **NAS 管家**。

开发者和发布者为 [kaf](https://club.fnnas.com/home.php?mod=space&uid=91804)。
