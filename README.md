# NAS 管家

NAS 管家是为飞牛 fnOS 开发的桌面和移动端工具。您可以在仪表盘查看日程，在浏览器里连接远程设备，也可以为日常维护设置计划任务和消息提醒。

## 下载安装

前往 [GitHub Releases](https://github.com/kaf931/fnos-manager/releases) 查看更新说明，下载与 NAS 架构匹配的 `.fpk` 安装包（x86_64 或 ARM64），在飞牛「应用中心 → 手动安装」中选择该文件。

## 主要功能

| 菜单 | 用途 |
| --- | --- |
| 仪表盘 | 自由排列日历、便签和常用工具，查看天气；在日历上点选日期即可添加提醒。 |
| 桌面图标 | 将 Docker 应用、常用网址或管家的单个功能添加到飞牛桌面。 |
| 计划任务 | 按计划启停应用或容器、执行脚本、唤醒设备，并查看运行结果。 |
| 远程连接 | 用 SSH 管理主机和文件，通过 VNC、RDP 访问远程桌面，通过 ADB 连接 Android 设备。 |
| 存储管理 | 分析目录占用、查找重复文件、批量改名，清理应用附件和历史记录。 |
| 网络唤醒 | 唤醒局域网设备，也可关联 SSH 连接执行重启或关机。 |
| 通知中心 | 创建提醒事项，通过应用内消息、邮件、企业微信、钉钉或飞书等渠道接收通知。 |
